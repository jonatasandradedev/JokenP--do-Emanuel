## 🎮 JokenPô

Este projeto foi desenvolvido durante as aulas de JavaScript com o objetivo de aprofundar os conhecimentos em lógica de programação e estruturas fundamentais da linguagem.

A aplicação simula o clássico jogo JokenPô (pedra, papel e tesoura), permitindo que o usuário escolha uma opção enquanto a máquina realiza uma escolha aleatória.

Durante o desenvolvimento, foram praticados conceitos como funções, objetos, arrays, estruturas condicionais, manipulação do DOM, geração de números aleatórios e controle de pontuação.


## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Manipulação do DOM
* Funções
* Arrays
* Objetos
* Estruturas condicionais
* Git e GitHub



## ⚙️ Funcionalidades

* Escolha entre pedra, papel e tesoura.
* Escolha aleatória da jogada da máquina.
* Identificação automática de vitória, derrota ou empate.
* Sistema de pontuação para o jogador e para a máquina.
* Atualização da pontuação diretamente na página.
* Exibição do resultado de cada rodada.
* Interação com os botões por meio de eventos JavaScript.
* Utilização de `Math.random()` e `Math.floor()` para gerar a jogada da máquina.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados:

* Criação e utilização de funções em JavaScript.
* Utilização de funções arrow.
* Manipulação do DOM com `querySelector()` e `innerHTML`.
* Criação e utilização de objetos e arrays.
* Uso de constantes para organização das opções do jogo.
* Aplicação de estruturas condicionais `if`, `else if` e `else`.
* Geração de valores aleatórios com `Math.random()` e `Math.floor()`.
* Implementação de lógica para vitória, derrota e empate.
* Controle e atualização de pontuação.
* Organização do código utilizando padrões de nomenclatura como Camel Case e Snake Case.
